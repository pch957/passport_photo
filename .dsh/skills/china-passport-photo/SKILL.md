# 中国护照电子证件照处理 Skill (`china-passport-photo`)

当用户要求处理中国护照、签证或“中国领事”App电子证件照时，严格遵循本规范并使用 Python 脚本进行自动化离线处理。

## 1. 核心尺寸与规格（硬性标准）
- **画布尺寸**：宽 354 像素 × 高 472 像素（对应 33mm × 48mm，600 DPI）。
- **头部比例**：
  - 头部宽度（两耳之间）：177 px – 260 px（15mm – 22mm）。
  - 头部高度（下巴至头顶）：330 px – 390 px（28mm – 33mm）。
  - 头顶留白（头顶距图片上边缘）：35 px – 59 px（3mm – 5mm）。
  - 下巴距图片下边缘：≥ 82 px（≥ 7mm）。
- **背景颜色**：纯白色 `RGB(255, 255, 255)`，无渐变、无阴影。
- **文件格式与体积**：24位真彩色 JPEG（`.jpg`），文件大小严格控制在 **40KB – 75KB** 之间。
- **严禁使用生图模型重绘人脸**，必须保留真实面部特征。

## 2. 脚本清单与调用

工作目录下的脚本（依赖 `rembg`、`opencv-contrib-python-headless`、`pillow`、`numpy`）：

| 脚本 | 用途 |
| --- | --- |
| `process_passport.py` | 主流程：抠图 → 人脸定位 → 校正缩放构图 → 纯白化 → 压缩 → 自检 |
| `make_debug.py` | 复核任意一张证件照的头廓并画线，打印规格表（成品交付前自查用） |
| `test_geometry.py` | 标定/回归测试，改动测量或缩放逻辑后必须跑 |

```bash
# 常规处理（--debug 出左右对照图，--strict 让不合规以非零码退出）
venv/bin/python3 process_passport.py <input_image> <output_image> --debug --strict

# 只复核一张现成的照片（影楼给的、别处做的）
venv/bin/python3 make_debug.py <photo.jpg> check.png --ref <原图.jpg> --ref-rembg

venv/bin/python3 test_geometry.py        # 期望输出：N passed, 0 failed
```

模型自动下载到 `models/` 并做 sha256 校验：YuNet `face_detection_yunet_2023mar.onnx`（230 KB，必需，注意 opencv_zoo 走 git-LFS，只能用 `media.githubusercontent.com` 域名）；FacemarkLBF `lbfmodel.yaml`（54 MB，可选，`--refine auto` 时本地有就用）。

### 核心处理逻辑分解
1. **抠图去背**：本地 `rembg`（`isnet-general-use` + alpha matting）抠出主体，合成到纯白底。
2. **人脸定位**：`cv2.FaceDetectorYN`（YuNet 神经网络检测器）一次给出人脸框 + 5 关键点（左右瞳孔中心 / 鼻尖 / 左右嘴角）。**禁止再用 `haarcascade_eye.xml` 之类 Haar 眼睛级联**——v1 那套不仅不准，代码本身也是坏的。
3. **瞳孔亚像素精修**：YuNet 关键点精度随检测尺度波动（同一张图跨尺度倾角能差 ±3°），故在眼位邻域做暗度加权质心重定瞳孔中心，跨尺度误差压到 <0.4°；嘴角线只作交叉校验（差 >3° 提示人工确认）。
4. **头廓测量**：头顶 = 抠图剪影在人脸窗口内第一个连续成片的行；下巴 = 眼线 + 1.77×瞳距（可选 FacemarkLBF 68 点给出真实下颌最低点）；两耳之间 = 眼线到下巴之间剪影跨度的高分位数。**源图与成品必须用同一套量法**，否则自检数字会互相打架。
5. **校正与构图**：水平校正 + 缩放 + 定位合成一次仿射重采样（避免多次插值糊化），残差倾斜 >1.5° 时二次校正。
6. **背景纯白化**：从边缘泛洪把近白背景压成 255，**泛洪必须以抠图遮罩为屏障**，否则浅色衣服上的高光会顺连通路径被刷白，在胸口留下缺口。
7. **体积二分压缩**：二分 `quality` 把 JPEG 压进 40–75 KB，写入 600 DPI。
8. **输出结果与报告**：汇报像素尺寸、文件大小与各项合规状态，并用 Markdown 图片语法（绝对路径）展示成品与调试图。

## 3. 约束冲突的处理策略（重要）

规范同时要求头高 330–390 与两耳之间 177–260，两者之比上限 260/330 ≈ 0.79。**耳朵外张、发量厚的头型（实测宽/高 ≈ 0.82）数学上无法同时满足**。脚本的取舍是：

> 构图留白 > 头部高度 > 头部宽度

宽度超限时输出 `WARN` 并给出换算过程（压到 260 px 时头高只剩多少），**不把头部缩到 330 px 下限以下**——人脸识别看的是头部尺寸，缩头是更糟的选择。`WARN` 不算失败，`--strict` 也不会因此退出非零。遇到这种情况要如实告诉用户冲突原因，不要谎称全部合规，也不要反复重跑试图"蒙"过去。

## 4. 汇报要求

- 成品与调试图用 Markdown 图片语法 + **绝对路径**内嵌：`![中国护照证件照](/abs/path/out.jpg)`。
- 自检表逐项列出实测值 / 要求 / PASS-WARN-FAIL，`WARN` 与 `FAIL` 附原因。
- 不要为了凑合规数字反复调参；测量结果有 ±3 px 抖动属正常（磁盘 JPEG 与压缩前画布的差异）。
